# kyi-site

Personal website for Kyi Wai Thant. Plain HTML/CSS, no build step.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy on GitHub Pages
1. Create a repo named `kiwi-Per.github.io` on GitHub.
2. Push this folder to it (`git remote add origin ... && git push -u origin main`).
3. The site goes live at https://kiwi-Per.github.io within a minute or two.
